# 🤖 AI Interview Agent

An AI-powered Interview Agent built using FastAPI, React, and Ollama for conducting technical interviews and generating intelligent feedback.

---

## Features

- AI-generated interview questions
- Candidate profile-based interviews
- Session memory
- Real-time scoring
- AI-generated interview feedback
- Strengths & Areas to Improve
- Hiring Recommendation
- Modern React Frontend
- FastAPI Backend
- Ollama (Llama3.2)

---

## Tech Stack

### Frontend

- React
- Vite
- Axios
- React Router

### Backend

- FastAPI
- Python
- Ollama
- Llama3.2

## Installation

### Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
